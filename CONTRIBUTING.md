# Contributing

Setup is in the [README](README.md). Architecture and conventions are in
[CLAUDE.md](CLAUDE.md). `mise tasks` lists every command.

## Licensing

lapidarium is [MIT](LICENSE) and contributions come in under the same license.
By opening a pull request you confirm you wrote the code or have the right to
submit it. You keep your copyright. There is no CLA.

## Before a pull request

Run `mise run fullcheck`. CI runs the same.

## Bugs

Open an issue. Security problems go to the address in the repository profile.
